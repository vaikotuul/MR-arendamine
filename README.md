## Mobiilrakenduste arendamine - Grupp 0

### Tech stack

- Android Studio Quail 3 (2026.1.3)
- Kotlin 2.4
- Android SDK 36
- Jetpack Compose

### Projekti käivitamine

1. Klooni repository:
   git clone https://github.com/vaikotuul/MR-arendamine

2. Ava projekt Android Studios.

3. Vali Android Emulator (vajab eraldi set-upimist) või füüsiline Android-seade.

4. Vajuta Run.
